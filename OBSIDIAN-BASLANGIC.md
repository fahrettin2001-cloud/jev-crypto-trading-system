# Jev projesi — başlangıç

Bu klasör, ortak GitHub projesinin bilgisayardaki kopyasıdır ve Obsidian kasası olarak açılabilir.

- [[GOREVLER]]: ekip görevleri ve sorumlular.
- [[docs/PROJE_HAFIZASI|Proje hafızası]]: proje özeti, karar şablonları ve kurtarma planı.
- [[docs/Obsidian-Baglanti-Testi|Bağlantı testi]]: ilk GitHub aktarımı.
- [[docs/Obsidian-Calisma-Dongusu|Çalışma döngüsü]]: notları güncelleme ve paylaşma planı.

Bu kasa henüz otomatik olarak GitHub ile eşitlenmez. Önce değişiklikleri koruyarak güncel GitHub sürümünü alın; değişikliklerinizi gözden geçirip commit ve push yapın. API anahtarlarını, şifreleri, veritabanlarını ve özel kişisel notları depoya eklemeyin. Obsidian uygulama ayarları Git'e dahil edilmez.
